## 📖 About

Cognitia is a web-based LMS built for schools. It gives students one place to keep track of their schoolwork, gives professors tools to post coursework and manage grades, and gives administrators control over the whole system.

## 👥 User Roles

### 🎓 Student
- View and manage workloads and deadlines
- Take quizzes
- Submit assignments and activities
- Check grades

### 👩‍🏫 Professor
- Upload quizzes, activities, and assignments
- Manage and encode student grades
- Monitor student submissions

### 🛠️ Admin
- Control and manage the entire LMS
- Manage user accounts (students and professors)
- Oversee courses, classes, and system settings

## ✨ Features

- Role-based access (Student, Professor, Admin)
- Workload and task management
- Quiz creation and taking
- Assignment and activity submission
- Grade management and viewing
- Admin dashboard for system control
